Two new features to secure API access are now available:

- **Read-only API keys** allow you to grant data access without write permissions
- **IP whitelisting** restricts API access to specified IP addresses, adding network-level protection for your infrastructure

Both can be [configured from the API section](https://www.latitude.sh/dashboard/api-keys) in your Dashboard.

[Learn more](https://www.latitude.sh/docs/api-reference/authentication)
