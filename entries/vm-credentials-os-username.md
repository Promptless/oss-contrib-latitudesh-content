---
title: "VM credentials now show OS-specific usernames"
slug: "vm-credentials-os-username"
type: "VMs"
dateOfRelease: "2026-04-07T00:00:00.000Z"
---

VM credentials now show the correct SSH username for each operating system. CentOS VMs display `centos`, and other distributions show their configured default user.

When no OS release is configured, the username defaults to `ubuntu`.
