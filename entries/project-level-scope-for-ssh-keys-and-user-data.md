Users can now add SSH keys and User data scripts at the project level. 

When creating these resources, you can choose whether to make them available across all projects or scope them to a specific one.

![Scope Selection](https://images.ctfassets.net/6k3y6xecqfv8/4QtKRSd6OijepFwXyo886T/0a262e79221a96235c9dc51f7dab808b/Scope_Selection.png)

These resources are now grouped by their scope during selection, making it easier to find and choose the right keys and scripts.

Check out the Docs for [SSH keys](https://www.latitude.sh/docs/servers/ssh-keys#project-and-team-scope) and [User data](https://www.latitude.sh/docs/servers/user-data#project-and-team-scope) to learn more.
