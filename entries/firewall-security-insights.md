Firewalls now show a security note when any rule allows traffic from all IP addresses (`any`, `0.0.0.0/0`, or `::/0`).

A clickable row appears on the Overview tab linking to the Rules tab, where an informational note displays at the top of the rules list. This makes it easy to spot open ports without reviewing each rule individually.

Head to [Network > Firewalls](https://www.latitude.sh/dashboard/networking/firewall) in your Dashboard to see it in action.
