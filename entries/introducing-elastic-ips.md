You can now create portable IPv4 addresses and move them between bare metal servers in a project, from the dashboard or via the API, no support ticket required.

[<u>Elastic IPs</u>](https://www.latitude.sh/docs/networking/elastic-ips) are provisioned on demand and can be reassigned between servers as often as needed: each team gets up to 5 by default, so no more DNS updates or reconfiguring your integrations with each server change.

Head to [<u>Network > IP addresses</u>](https://www.latitude.sh/dashboard/networking/elastic-ips) to get started.
