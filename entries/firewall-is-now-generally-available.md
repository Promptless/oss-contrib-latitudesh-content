We're proud to announce that Firewall has officially moved to General Availability and is now fully supported for all users. 

Key benefits include:

• Centralized management of inbound and outbound traffic rules.

• Default blocking of unspecified traffic.

• Easy assignment of firewalls to multiple servers.

Pricing is set at **$4.00 per server**.

[Check out the Docs to learn more](https://www.latitude.sh/docs/networking/firewall)
