We have added new custom images to our examples list, offering more customization options for deploying operating systems tailored to your needs. The new custom images include:

- [**<u>Harvester</u>**](https://github.com/latitudesh/examples/tree/main/custom-image-harvester)**:** Cloud-native, open-source software built on Kubernetes that makes it easy to deploy and manage virtualized workloads.
- [**<u>AlmaLinux 8 and 9:</u>**](https://github.com/latitudesh/examples/tree/main/custom-image-almalinux-9)** **Open-source enterprise Linux distributions that offer long-term stability and a reliable platform for production use.
- [**<u>Oracle Linux 9:</u>**](https://github.com/latitudesh/examples/tree/main/custom-image-oracle-linux-9) a distribution packaged and distributed freely by Oracle, partially available under the [<u>GNU General Public License</u>](https://www.gnu.org/licenses/gpl-3.0.en.html) since late 2006.
- [**<u>Ubuntu 24:</u>**](https://github.com/latitudesh/examples/tree/main/custom-image-ubuntu-24) a Linux distribution developed by Canonical. You can deploy it using the default image provided by [<u>Latitude.sh</u>](http://latitude.sh), or create your own Ubuntu-based custom image using this example as a reference.

[<u>Learn more about Custom Images →</u>](https://www.latitude.sh/docs/servers/custom-images)
